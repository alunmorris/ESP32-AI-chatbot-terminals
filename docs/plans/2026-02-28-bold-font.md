# Bold Font (Large Font Mode) Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Replace Font 2 (16px fixed-width) with FreeSansBold9pt7b in large-font mode.

**Architecture:** TFT_eSPI already has GFX FreeFont support compiled in (`LOAD_GFXFF` set). Swap `setTextFont(2)` for `setFreeFont(&FreeSansBold9pt7b)` throughout, and swap `setCursor+print` for `drawString` in all large-font sections (GFX fonts use baseline for `print()` but top-of-character for `drawString()`). Update `LINE_H_LARGE` and `SPLASH_H` constants.

**Tech Stack:** ESP32, TFT_eSPI 2.5.43, FreeSansBold9pt7b (bundled with TFT_eSPI), PlatformIO

**Context:** `rebuildLines()` calls `tft.setTextFont(2)` at line ~317 to measure word widths with `tft.textWidth()`. `drawHistory()` calls it at line ~416 to render lines. Both need to use the GFX font instead. In `drawHistory()`, replace `setCursor+print` with `drawString` since GFX fonts position y at baseline with `print()` but at top-of-character with `drawString()`.

**Step 1: In rebuildLines() — swap setTextFont(2)**

Change (line ~317):
```cpp

```
To:
```cpp

```

**Step 2: In drawHistory() — swap font set and rendering**

Change (line ~416):
```cpp
if (largeFont) tft.setTextFont(2); else tft.setTextSize(1);
```
To:
```cpp
if (largeFont) tft.setFreeFont(&FreeSansBold9pt7b); else tft.setTextSize(1);
```

Change (line ~423-424) — swap setCursor+print for drawString:
```cpp

        tft.print(lines[idx]);
```

To:
```cpp
        if (largeFont) tft.drawString(lines[idx], 0, i * lineH);
```

### Task 3: Swap font calls in connectWiFi() and selectModel()

**Context:** There are 5 remaining `setTextFont(2)` calls — one in `connectWiFi()` (boot splash) and four in `selectModel()` (model confirmation screens and 'b'/'i' key handlers). All use `setCursor+print` which must become `drawString`.

**Step 1: connectWiFi() splash (lines ~761–772)**

Change:
```cpp

        tft.setTextColor(TFT_YELLOW, COL_BG);
        tft.setCursor(0, 0);
        tft.print("CYD AI chatbot v: -0.1.");
```
